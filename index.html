♡ Catatan keamanan dan batasan

File diproses di browser dan tidak diunggah oleh kode aplikasi ini. Library PDF/DOCX/OCR dimuat dari CDN pihak ketiga. Hasil OCR dapat keliru; pemeriksaan piksel dapat sensitif terhadap perubahan ukuran, kompresi, atau posisi. Hash cocok berarti byte file sama dengan referensi, bukan bukti identitas pembuat atau keabsahan hukum dokumen. Jangan gunakan hasil ini sebagai satu-satunya dasar keputusan penting.
